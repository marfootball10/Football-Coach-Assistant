# ⚽ Football Coach Assistant

V rámci projektu Football Coach Assistant pracujem na časti,
ktorá sa týka **vytvorenia profilu hráča**.

Cieľom tejto časti je vytvoriť jednoduchú stránku, cez ktorú
si tréner bude môcť vytvoriť profil jednotlivých hráčov
a uložiť si o nich základné informácie.

## Čo má moja časť projektu robiť:

Na stránke bude možné vytvoriť profil hráča a vyplniť
jeho základné údaje.

Pri vytváraní profilu zadávam:

- vek
- výšku
- váhu
- pozíciu

Okrem toho bude mať každý hráč aj základné hodnotenie
svojich schopností.

## Skills hráča

Hráča budem hodnotiť v štyroch základných oblastiach:

- **Rýchlosť**
- **Technika**
- **Defenzíva**
- **Mentálna odolnosť**
